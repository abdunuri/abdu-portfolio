# Abdulaziz Nuri Portfolio

This is the source project for Abdulaziz Nuri's personal portfolio website.

## Main Concept

The portfolio presents Abdulaziz as a full-stack and automation developer focused on practical software for real workflows. It highlights full-stack web apps, automation systems, Telegram bots, dashboards, scraping, and business workflow tools.

## Site Sections

- Hero with name, role, calls to action, and availability
- Capability cards for what Abdulaziz builds
- Featured projects such as Gagari, Techvent, passport automation, LinkedIn automation, NURSAD TECH, and trade signal automation
- About section
- Skills and stack groups
- Experience and certifications
- Contact links for email, GitHub, Telegram, Upwork, Fiverr, and NURSAD TECH

## Tech Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- GitHub Pages static export

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Content Editing

Most portfolio content lives in `src/data/index.ts`. Update project descriptions, skills, experience, and links there before changing component code.

## Deployment

The project is configured for static export and GitHub Pages deployment. Build with:

```bash
npm run build
```
